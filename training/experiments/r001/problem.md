# r001 问题：小模型能否只靠 Teacher 数据学会槽位抽取

- 目标：Qwen3-0.6B（主）/ 1.7B（对照）经 LoRA SFT 后，在 L2 主集上接近 DeepSeek 基线
  （98.3%，59/60），holdout 通过率 ≥ 85%（DeepSeek 88.9%，24/27）。M2 门槛：0.6B 主集 ≥ 基线 − 5pp。
- 未微调的基座模型在同一 prompt 下的表现作为下限（I6 一并评测）。
- 已知风险：
  - 训练集 782 条全部由 gpt-5 生成，评测集为人工编写，存在说法分布差异；
  - DeepSeek 基线的 4 个错误集中在「该不该输出某个键」（any / null 混淆、确认轮多抽键、声音 vs. 风格），
    小模型很可能在同样的位置出错；
  - 0.6B 的中文口语与黑话理解能力有限，`style_preference` 的概括可能偏离用户原话。
